Projeto Meu Portfólio

Este projeto é um portfólio pessoal criado para apresentar minhas informações, habilidades e projetos.

O site foi desenvolvido utilizando HTML5 para estruturar a página, CSS para estilizar, JavaScript para adicionar interatividade e Bootstrap para facilitar a criação do layout.

O portfólio possui menu de navegação, apresentação pessoal, habilidades técnicas, projetos, formulário de contato, opção para mudar entre o tema claro e escuro e mostra a ultima visita, 
com horário e data, alem do ano atual.
